### 3.2. ¿Qué es Apache?

Apache es un programa que se utiliza como servidor web. Dicho de forma sencilla, es el encargado de mostrar las páginas web cuando una persona quiere entrar en ellas.

Por ejemplo, cuando buscamos una página en Google y entramos, nuestro navegador se conecta con un servidor para pedirle esa página. Si el servidor utiliza Apache, este programa se encarga de recibir la petición y mandar la información.

Apache es gratuito y lo puede utilizar cualquier persona. Además, funciona en distintos sistemas operativos, como Windows y Linux.

### 3.3. ¿Para qué sirve Apache?

Apache sirve para que podamos tener páginas web funcionando en un servidor.

Por ejemplo, si hacemos una página con HTML y CSS, podemos utilizar Apache para verla desde el navegador.

También podemos utilizarlo para trabajar con PHP, que es otro lenguaje que estamos aprendiendo en clase.

Una cosa buena es que no necesitamos subir nuestras páginas a Internet para probarlas, porque podemos instalar Apache en nuestro ordenador y verlas usando `localhost`.

Esto nos viene muy bien para hacer ejercicios, comprobar errores y aprender cómo funciona una página antes de publicarla.

### 3.4. Historia de Apache

Apache apareció en 1995, cuando varios programadores empezaron a mejorar un servidor web que ya existía.

Con el tiempo se fue haciendo muy conocido porque era gratuito y funcionaba bastante bien.

En 1999 se creó la Apache Software Foundation, que es una organización que se encarga de apoyar proyectos de programas gratuitos y de código abierto.

Apache se convirtió en uno de los servidores web más utilizados y, aunque ahora hay más alternativas, todavía se sigue usando.

### 3.5. Alternativas a Apache

Apache no es el único programa que sirve para crear un servidor web. Hay otros que hacen prácticamente lo mismo.

- **Nginx:** Es parecido a Apache y también sirve para mostrar páginas web. Una de sus ventajas es que puede trabajar con muchas conexiones al mismo tiempo.
- **Microsoft IIS:** Este programa es de Microsoft y se utiliza sobre todo en servidores que tienen Windows.
- **LiteSpeed:** Es otro servidor web que se utiliza para alojar páginas de Internet. Destaca porque tiene un buen rendimiento.

Al final, todos sirven para una cosa parecida, aunque cada uno funciona de una manera diferente.
